Welcome to Greenpower Telemetry
Live telemetry — speed, power, temps, RPM, IMU, ESC and link quality, updating live several times a second.
Raceline map — live GPS position and trail on satellite imagery.
Sessions — every run is saved automatically and exportable as CSV.
Multi tab — overlay several metrics on one chart to spot correlations.
Test Mode (in Settings) — try the UI with sample data, no car needed.
Forwarding From the Receiver?
If you're at the track with the receiver plugged into this computer, install the receiver agent to relay live telemetry here. Not needed just to watch the dashboard.
Make It Yours
Settings has a few quick options — default chart time range, haptics, test mode, and (on mobile) which Overview boxes show and how many per row.
Clear Website Data?
This resets every saved preference on this device (Settings, dismissed prompts, the access gate) and reloads the page. It does not affect the live telemetry itself.
Delete This Session?
This permanently deletes session #-- and every telemetry point recorded in it. This cannot be undone.
